NOVA — progetto PWA iniziale

COSA FUNZIONA
- Interfaccia futuristica con occhi animati.
- Chat testuale dimostrativa.
- Sintesi vocale italiana (se supportata dal dispositivo/browser).
- Riconoscimento vocale tramite Web Speech API (supporto variabile tra browser).
- Struttura PWA e cache offline.

IMPORTANTE
Questa versione NON è ancora collegata a un modello AI: le risposte sono dimostrative.
Per avere risposte intelligenti e libere serve collegare un servizio AI o un modello locale.
Non inserire chiavi API segrete direttamente nei file pubblici del sito.

COME PUBBLICARLA
1. Estrai la cartella.
2. Pubblica i file su un hosting statico che fornisca HTTPS (ad esempio GitHub Pages).
3. Apri l'indirizzo HTTPS da Windows o iPhone.

INSTALLAZIONE
- Windows/Chrome o Edge: apri il sito e usa l'icona Installa nella barra degli indirizzi, oppure menu > Installa NOVA.
- iPhone: apri il sito in Safari > Condividi > Aggiungi alla schermata Home.

NOTA VOCALE
Il riconoscimento vocale dipende dal browser e dal sistema operativo. Su iPhone, se il microfono web non è disponibile, puoi usare la dettatura della tastiera. La sintesi vocale usa le voci italiane installate sul dispositivo.
